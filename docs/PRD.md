# Dungeons & Dragons AI - Product Requirements Document

## Project Overview

**Name:** Dungeons & Dragons AI  
**Type:** Web-based RPG game with AI-generated content  
**Goal:** Create an immersive D&D-style game experience where AI generates adventures, stories, and images dynamically.

---

## Tech Stack

### Frontend
- **Framework:** React.js with Vite
- **Styling:** Tailwind CSS
- **State Management:** React Context API or Zustand
- **Build Tool:** Vite

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** SQLite
- **API:** REST API with JSON responses

### AI Services
- **Story/Text Generation:** Groq API
  - Model: Llama 3.3 70B Versatile
  - Endpoint: `https://api.groq.com/openai/v1/chat/completions`
  - Fast inference with free tier
- **Image Generation:** Pollinations.ai
  - Free tier API with API key
  - REST API for programmatic access

## Core Features

### 1. Home/Landing Page
- Clean, atmospheric hero section with fantasy theme
- Two main CTAs:
  - **"Generate New Adventure"** - Create a fresh story
  - **"Story Library"** - Browse saved adventures
- Simple nav menu: Home, Library, Settings

### 2. Story Generator

#### 2.1 Automatic Generation
- User clicks "Generate New Adventure"
- AI generates a complete adventure with:
  - **Setting** (e.g., "A haunted tavern in the misty hills")
  - **Main Quest** (e.g., "Find the lost amulet of light")
  - **NPCs** (names, descriptions, motivations)
  - **Key Scenes** (3-5 pivotal moments)
  - **Starting Inventory** (basic gear)

#### 2.2 Custom Generation
- User provides:
  - **Setting theme** (fantasy, horror, sci-fi, etc.)
  - **Tone** (serious, humorous, dark)
  - **Difficulty** (easy, medium, hard)
  - **Custom context** (optional free-text)
- AI tailors adventure to these parameters

#### 2.3 Image Generation
- For each key scene, generate an atmospheric image:
  - Scene illustrations for plot points
  - NPC portraits
  - Item/treasure visuals
- Store Pollinations.ai URLs in database

### 3. Game Play

#### 3.1 Game Flow
1. **Scene Presentation** - Show scene description + image
2. **Choices** - AI provides 3-4 action options
3. **Player Decision** - User selects choice
4. **Dice Roll** - Roll d20 for outcome modifier
5. **AI Response** - Narrates result based on choice + roll
6. **Progress** - Move to next scene or conclude

#### 3.2 Character Sheet (Simplified)
- **Name** (user-defined)
- **Class** (Fighter, Wizard, Rogue, Cleric, Ranger)
- **Stats:** STR, DEX, INT, WIS, CON, CHA (rolls 3d6 each)
- **HP:** Based on class + CON modifier
- **Inventory:** Items collected during adventure
- **Gold:** Currency for purchases/rewards

#### 3.3 Combat System (Simplified)
- Turn-based against AI-generated enemies
- **Attack Roll:** d20 + relevant stat vs enemy AC
- **Damage:** Weapon dice + stat modifier
- **Enemy AI:** Generated by Groq API per encounter
- **Death:** Game over or restart from checkpoint

#### 3.4 Skill Checks
- Ability-based checks: "Roll for DEX to dodge" → d20 + DEX
- Difficulty Classes (DC): Easy (10), Medium (15), Hard (20)
- Success/failure affects narrative path

### 4. Story Library

#### 4.1 Save System
- **Auto-save:** After each scene
- **Manual save:** User can save at any time
- **Save Data:**
  - Adventure metadata
  - Current scene index
  - Character state (HP, inventory, gold)
  - Game history (choices made, dice rolls)

#### 4.2 Browse & Resume
- List all saved games with:
  - Adventure title
  - Date last played
  - Current scene/progress
  - Thumbnail (first scene image)
- "Resume" button continues where left off
- "Delete" option to remove saves

#### 4.3 Replay Adventures
- Option to replay from beginning
- Different choices = different outcomes (branching paths)

### 5. Settings

#### 5.1 User Preferences
- **Image Style** - Realistic, fantasy art, cartoon, etc. (affects Pollinations.ai prompts)
- **Difficulty Toggle** - Easy/Medium/Hard (affects DCs and enemy strength)
- **Sound Effects** - On/Off (if implemented later)
- **Dice Animations** - On/Off

#### 5.2 AI Configuration
- **Groq API:** Verify API key and model availability
- **Pollinations.ai:** Verify image generation API key
- **Model selection:** Fixed to llama-3.3-70b-versatile (can be changed in .env)

## Database Schema (SQLite)

### Tables

```sql
-- Adventures (generated stories)
CREATE TABLE adventures (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  title TEXT NOT NULL,
  description TEXT,
  setting TEXT,
  quest TEXT,
  difficulty TEXT,
  generated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Scenes
CREATE TABLE scenes (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  adventure_id INTEGER,
  scene_order INTEGER,
  description TEXT,
  image_url TEXT,
  choices TEXT, -- JSON array of options
  is_key_scene BOOLEAN DEFAULT 0,
  FOREIGN KEY (adventure_id) REFERENCES adventures(id)
);

-- NPCs
CREATE TABLE npcs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  adventure_id INTEGER,
  name TEXT,
  description TEXT,
  role TEXT,
  image_url TEXT,
  FOREIGN KEY (adventure_id) REFERENCES adventures(id)
);

-- Saved Games
CREATE TABLE saved_games (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  adventure_id INTEGER,
  character_name TEXT,
  character_class TEXT,
  stats TEXT, -- JSON: {STR, DEX, INT, WIS, CON, CHA}
  hp INTEGER,
  inventory TEXT, -- JSON array of items
  gold INTEGER DEFAULT 0,
  current_scene_id INTEGER,
  game_history TEXT, -- JSON array of choices/rolls
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_played TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (adventure_id) REFERENCES adventures(id),
  FOREIGN KEY (current_scene_id) REFERENCES scenes(id)
);

-- Settings (single row)
CREATE TABLE settings (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  image_style TEXT DEFAULT 'fantasy art',
  difficulty TEXT DEFAULT 'medium',
  dice_animations BOOLEAN DEFAULT 1
);
```

## API Endpoints

### Story Generation
- `POST /api/adventures/generate` - Generate new adventure
  - Body: `{ theme, tone, difficulty, context }`
  - Response: `{ adventureId, title, scenes, npcs }`
- `GET /api/adventures/:id` - Get adventure details
- `GET /api/adventures` - List all generated adventures

### Game Play
- `POST /api/games/start` - Start new game
  - Body: `{ adventureId, characterName, characterClass }`
  - Response: `{ gameId, initialScene, character }`
- `GET /api/games/:id` - Get current game state
- `POST /api/games/:id/choice` - Submit player choice
  - Body: `{ choiceId, diceRoll }`
  - Response: `{ nextScene, outcome, characterState }`
- `POST /api/games/:id/save` - Manual save

### Saved Games
- `GET /api/saved-games` - List all saved games
- `DELETE /api/saved-games/:id` - Delete saved game

### Settings
- `GET /api/settings` - Get user settings
- `PUT /api/settings` - Update settings
- `GET /api/ai/test` - Test Groq and Pollinations.ai connections

## AI Prompts (Groq API)

### Adventure Generation Prompt
```
You are a Dungeon Master. Generate a D&D adventure with these parameters:

Theme: {theme}
Tone: {tone}
Difficulty: {difficulty}
Additional context: {context}

Generate JSON with:
{
  "title": "Adventure title",
  "setting": "Setting description",
  "quest": "Main quest description",
  "npcs": [
    {"name": "Name", "description": "Description", "role": "Role"}
  ],
  "scenes": [
    {
      "description": "Scene narrative",
      "imagePrompt": "Image generation prompt",
      "choices": ["Option 1", "Option 2", "Option 3"],
      "isKeyScene": true
    }
  ]
}

Return ONLY valid JSON.
```

### Scene Response Prompt
```
You are the Dungeon Master. The player chose: "{playerChoice}"
Their d20 roll was: {diceRoll}
Their stats: {stats}

Describe what happens next based on:
- Their choice
- The dice roll (higher = better outcome)
- Their character stats

If the roll fails, provide a setback or alternative path.
If successful, reward them with progress or an item.

Return JSON with:
{
  "narrative": "Story description",
  "outcome": "success|failure|partial",
  "statChange": { "hp": -5, "gold": 10 },
  "newItem": "Item name (if awarded)",
  "nextScenePrompt": "Prompt for next scene generation"
}
```

## UI/UX Considerations

### Visual Design
- **Color Palette:** Dark theme (deep purples, golds, parchment tones)
- **Typography:** Fantasy-inspired fonts for headers (Google Fonts: Cinzel, MedievalSharp)
- **Layout:** 
  - Mobile-first responsive design
  - Three-column desktop: Image left, narrative center, choices right

- **Dice Roll:** 3D animated d20 spinner
- **Scene Transition:** Fade in/out with atmospheric effect
- **Image Load:** Skeleton loader then smooth reveal
- **Choice Selection:** Highlight and expand on hover

- Keyboard navigation for all choices
- Screen reader support (ARIA labels)
- High contrast mode option
- Adjustable text size

## Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| Groq API changes/rate limits | High | Version-pin models, prompt structure, implement retry logic |
| Pollinations.ai downtime | Medium | Fallback to placeholder images |
| Slow LLM response | Medium | Add loading animations, timeout handling |
| SQLite corruption | Low | Regular backups, migrations |
| Poor AI narrative quality | High | Iterative prompt testing, user feedback |
